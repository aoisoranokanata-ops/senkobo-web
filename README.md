# 線工房 Web

iPad（Safari・ホーム画面に追加）で使える、ロゴ・アイコン・イラスト制作アプリ。
Windows 版の「線工房」（Illustrator 相当）のブラウザ版で、作品ファイル **.snk** はそのまま行き来できます。

**開く**: https://aoisoranokanata-ops.github.io/senkobo-web/

## できること（v0.3.0）
- 作品ギャラリー（端末のブラウザの中に自動保存）
- 道具: 選択（移動・拡大縮小・回転）・ダイレクト選択（錨点とハンドル）・ペン・鉛筆・長方形・角丸長方形・楕円・多角形・スター・直線・文字・スポイト・手のひら
- 塗りと線（RGB / CMYK・スウォッチ）・線幅・線端・角・破線・不透明度・描画モード
- レイヤー・グループ・重ね順・整列・複製・複合パス・クリッピングマスク・取り消し
- 書き出し: .snk（Windows 版で開ける）・SVG・PNG（共有シートで「ファイル」や AirDrop へ）
- 画像の配置
- 文字: エリア内文字（四角でも円でも、形の中で折り返す）・パス上文字・縦書き（縦中横）・ルビ・ワープ（円弧・アーチなど）・
  文字の一部だけ色や大きさを変える（入力欄で範囲を選んで）
- グラデーション（パネルと、引っぱって向きを決めるツール）・縁取り（袋文字）・効果（ドロップシャドウ・光彩・ぼかし）
- 変形の数値（基準点・回転・反転）・アートボード（追加・大きさ・並べ替え・つかんで動かす）
- 形の計算: パスファインダー（合体・前面型抜き・交差・中マド・背面型抜き・分割）・パスのオフセット・線のアウトライン・連結・
  シェイプ形成ツール（重なった所をなぞって合体、消すモードで削除）。曲線は曲線のまま残ります

## iPad での操作
| 操作 | 動き |
|---|---|
| Apple Pencil | 描く・選ぶ（一度使うと、指は画面の移動になります） |
| 2 本指でつまむ・動かす | 拡大縮小・移動 |
| 2 本指でトン | 取り消し |
| 3 本指でトン | やり直し |
| ダブルタップ | 文字を直す・パスの錨点を編集・錨点の角⇔なめらか |
| 文字ツールでパスの線をタップ | 開いたパス → パスに沿う文字、閉じた形 → 形の中に流し込む文字 |

キーボードをつなげば Illustrator と同じショートカット（V・A・P・⌘Z・⌘G など）が使えます。

## 注意
- 作品はこの端末のブラウザの中に保存されます。Safari の「履歴とWebサイトデータを消去」で消えるので、大事な作品は .snk で書き出してください。
- 文字は端末のフォントで表示します（Windows 版とは字の形が少し違います）。
