# 線工房 Web

iPad（Safari・ホーム画面に追加）で使える、ロゴ・アイコン・イラスト・チラシの制作アプリ。
Windows 版の「線工房」（Illustrator 相当）のブラウザ版で、作品ファイル **.snk** はそのまま行き来できます。

**開く**: https://aoisoranokanata-ops.github.io/senkobo-web/
（Safari で開いて、共有 →「ホーム画面に追加」でアプリになります。一度開けばオフラインでも使えます）

## できること（v1.0.0）
- **作品ギャラリー**: 端末のブラウザの中に自動保存・サムネイル・複製・テンプレート
- **道具**: 選択（移動・拡大縮小・回転）・ダイレクト選択（錨点とハンドル）・ペン・鉛筆・長方形・角丸・楕円・多角形・スター・直線・
  文字・シェイプ形成・線幅・グラデーション・スポイト・アートボード・手のひら
- **塗りと線**: RGB / CMYK・スウォッチ・配色の提案・グラデーション（線形・円形）・線幅・線端・角・破線・線の形（筆・しずく…）・
  縁取り（袋文字）・不透明度・描画モード・効果（ドロップシャドウ・光彩・ぼかし）
- **文字**: ポイント・エリア内（四角でも円でも形の中で折り返す）・パス上・縦書き（縦中横）・ルビ・均等配置・禁則・ワープ・
  文字の一部だけ色や大きさを変える・アウトライン化
- **形の計算**: パスファインダー（合体・前面型抜き・交差・中マド・背面型抜き・分割）・パスのオフセット・線のアウトライン・連結・
  複合パス・クリッピングマスク・角を丸くする（曲線は曲線のまま）
- **並べる・印刷**: 整列・分布・重ね順・グループ・レイヤー・変形の数値・アートボード・定規・ガイド・グリッド・スナップ・
  PDF 書き出し（入稿用: CMYK のまま・トンボ・裁ち落とし・文字はアウトライン）・トンボを作成
- **超える機能**（上の「超える」メニュー）: 対称描画（左右・上下・放射・万華鏡）・再配色・バリエーション・
  アイコン一括書き出し（.ico・ファビコン・iOS・Android・macOS・PWA を zip で）・画像トレース
- **書き出し**: .snk（Windows 版で開ける）・SVG・PNG・PDF（共有シートで「ファイル」や AirDrop へ）

## iPad での操作
| 操作 | 動き |
|---|---|
| Apple Pencil | 描く・選ぶ（一度使うと、指は画面の移動になります） |
| 2 本指でつまむ・動かす | 拡大縮小・移動 |
| 2 本指でトン | 取り消し |
| 3 本指でトン | やり直し |
| ダブルタップ | 文字を直す・パスの錨点を編集・錨点の角⇔なめらか・線幅の点を消す |
| 定規から引っぱる | ガイド（定規へ戻すと消える） |
| 文字ツールでパスの線をタップ | 開いたパス → パスに沿う文字、閉じた形 → 形の中の文字 |

キーボードをつなげば Illustrator と同じショートカット（V・A・P・⌘Z・⌘G・⌘R など）が使えます。一覧は［表示］→［使い方とショートカット］。

## Windows 版との違い
- 文字は端末のフォントで組みます（iPad ではヒラギノ）。字の形・幅が Windows 版と少し違うことがあり、アウトライン化した形も端末のフォントの形です。
  フォントの OpenType 機能（約物の詰め・合字の切り替えなど）は使えません（設定は作品に残るので Windows 版で開けば効きます）。
- Windows 版にある Claude との連携・彩工房との直接の受け渡し・リンク画像はありません（画像はすべて作品の中に入ります）。

## 注意
- 作品はこの端末のブラウザの中に保存されます。Safari の「履歴とWebサイトデータを消去」で消えるので、大事な作品は［ファイル］→［.snk で保存］で書き出してください。
- 新しい版を公開すると、画面の右下に「新しい版があります」が出ます。［再読み込み］で切り替わります。
